# Gemma 4 Fine-tuning for Love Island Dialogue Generation

This directory contains scripts to fine-tune Google's Gemma 4 model on Love Island transcript data for generating realistic dialogue.

## Setup

1. Install dependencies:
```bash
cd finetune
pip install -r requirements.txt
```

2. Prepare training data:
```bash
python prepare_gemma_data.py
```
This converts your preprocessed transcripts into Gemma 4's instruction-tuning format and splits into train/val/test sets.

## Training

Fine-tune Gemma 4 using LoRA (parameter-efficient fine-tuning):

```bash
python train_gemma.py
```

**Configuration:**
- Model: `google/gemma-4-2b-it` (fast mode) or `google/gemma-4-9b-it` (full mode)
- Training: 1-3 epochs, batch size 4-8, gradient accumulation 2-4
- Quantization: 4-bit optional for memory efficiency
- LoRA: Rank 4-8, targeting attention layers

**Hardware requirements:**
- Gemma 4-2B: ~8GB GPU VRAM with 4-bit quantization
- Gemma 4-9B: ~16GB GPU VRAM with 4-bit quantization
- Ascent GX10: Can handle full precision with 128GB memory

## Inference

Test your fine-tuned model:

```bash
python inference.py
```

This will:
1. Load the fine-tuned model
2. Generate sample dialogue for individual characters
3. Simulate a multi-turn conversation between characters

## Files

- `prepare_gemma_data.py` - Converts preprocessed data to Gemma format
- `train_gemma.py` - Fine-tuning script with LoRA
- `inference.py` - Test and generate dialogue
- `data/` - Training data splits (generated by prepare script)
- `checkpoints/` - Saved model checkpoints

## Customization

**Change model size:**
Edit `MODEL_ID` in `train_gemma.py` and `inference.py`:
- `google/gemma-2b` (smaller, faster)
- `google/gemma-7b` (larger, better quality)

**Adjust training:**
Edit hyperparameters in `train_gemma.py`:
- `NUM_EPOCHS` - training epochs
- `BATCH_SIZE` - batch size
- `LEARNING_RATE` - learning rate
- `MAX_SEQ_LENGTH` - max sequence length

**Generate for specific characters:**
Edit the speakers list in `inference.py` to match your contestants.
